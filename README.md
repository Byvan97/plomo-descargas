# Plomo 🎩
Juego de cartas de mafiosos, Chicago 1927.

## ⬇️ [Descarga el juego aquí](https://github.com/byvan97/plomo-descargas/releases/latest)

No hace falta clonar nada: el juego no está en los archivos de esta página.

1. Entra en el enlace de arriba.
2. En **Assets**, baja **Plomo-Instalar-x.x.x.exe** y ábrelo.
3. Si Windows dice «Windows protegió su PC»: **Más información → Ejecutar de todas formas** (el juego no está firmado).
4. La primera vez que crees una partida, Windows pregunta si deja usar la red: **Permitir**.

Se actualiza solo cada vez que abres el juego.

**Para jugar juntos:** uno pulsa **Crear partida** y los demás **Unirse a una partida**. Tenéis que estar en la misma wifi.
